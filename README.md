# FitLife — QA Lab 3

Учебный проект для лабораторной работы №3 по дисциплине «Тестирование программного обеспечения автоматизированных систем».

## Состав

- PHP веб-приложение FitLife;
- ООП-модуль тренировок;
- Doxygen-конфигурация;
- изображения и график для документации;
- страница `oop_demo.php` для демонстрации работы классов;
- `schema.sql` для быстрого создания учебной базы данных FitLife.

## Иерархия

- `Workout -> StrengthWorkout -> GymWorkout`
- `Workout -> CardioWorkout -> RunningWorkout`

## Генерация документации

```bash
doxygen Doxyfile
```

После генерации главная HTML-страница находится в `docs/html/index.html`.
