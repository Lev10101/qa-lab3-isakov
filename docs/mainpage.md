# FitLife — документация ООП-модуля

## Назначение

FitLife — учебное веб-приложение для организации фитнес-тренировок. В рамках лабораторной работы в проект добавлен отдельный ООП-модуль, описывающий различные виды тренировок.

## Иерархия классов

Основой является абстрактный класс `Workout`. От него наследуются `StrengthWorkout` и `CardioWorkout`. Далее сформированы ещё два уровня специализации: `GymWorkout` наследуется от `StrengthWorkout`, а `RunningWorkout` — от `CardioWorkout`.

Таким образом, выполнено требование наличия минимум двух уровней иерархии:

`Workout -> StrengthWorkout -> GymWorkout`

`Workout -> CardioWorkout -> RunningWorkout`

## Формула

Для беговой тренировки используется упрощённая формула расчёта дистанции:

\f[
D = \frac{T}{P}
\f]

где `D` — расстояние в километрах, `T` — длительность тренировки в минутах, `P` — средний темп в минутах на километр.

Для оценки расхода калорий в силовой тренировке используется модель:

\f[
C = T \cdot (5 + 1.2I)
\f]

где `C` — оценочный расход калорий, `T` — длительность, `I` — интенсивность от 1 до 10.
